# Quick match

Added on 28 October 2026 (Part 3 of the fix list). Quick match is a waiting room, so it has to look like a place a player is happy to wait in, and say what is going on. It follows `qa-checklist.md` (Q1 to Q11).

- **U96** `/play/quick` starts with the header bar (Q12, U131), whose Home leaves the queue, and then the page header every page has (Q11): the cracked "RUBBLE" title and the subtitle "Quick match" in the heading style. Under it sits **one compact centred card** (`quick-panel`), at most 480px wide (Q3). **There is no Cancel button** (removed 31 October 2026: Home already leaves). Nothing else is on the page: one centred column (Q6).
- **U97** The card shows, from top to bottom: an **animated pair of discs** (`quick-discs`, a red ring disc and a yellow cross disc, so they differ by shape as well as colour, that swing towards each other and part again, using only `transform`, and standing still under reduced motion); the line **"Finding you a random opponent"** (`quick-status`, the heading style); the subtext **"Quick match pairs you with another person who is looking for a game right now"** (`quick-hint`, `--text-muted`); and the live count (`quick-live`).
- **U98** The live count (`quick-live`) has **its line reserved from the start**: before the count arrives the card looks exactly as it does once it has loaded, with the line's height already taken (an empty line of the same size), so the count arriving never moves anything (Q1, added 29 October 2026). The live count reads **"N people playing now"**, where N is twice the number of live quick match games from `/api/live` (R80), **"1 person playing now"** is never shown (a game has two people), and with no live game the line is **"Be the first to play"**. It is asked for when the screen opens and every 10 seconds while it is open (R77), and keeps its last words if the server cannot say.
- **U99** After **20 seconds** of waiting the offer of the computer appears **inside the same card** (`computer-offer`): "Nobody has arrived yet. Play the computer while you wait?" with one button, **Play the computer** (`computer-offer-play`). The card grows downwards only and nothing above it moves (Q1). Waiting continues until the player taps it or cancels.
- **U100** A message from the server or a failure ("Could not join Quick match. Try again.", "You are no longer waiting. Go back and try again.", "Could not start a game against the computer. You are still waiting.") replaces the status line inside the card. Home leaves the queue and goes Home (Q9). **Leaving the page in any other way** (the browser's back button, closing the tab, following another link) **also removes the ticket from the queue** (the page sends the leave when it is hidden), and the server forgets a ticket that stops asking within 10 seconds, so a player who has left is never matched afterwards (R35).
- **U101** The page works at 320px (the card's padding and the discs are smaller there, and so the card, even with the computer offer showing, is on the first screen): the card is the screen width minus 32px, every line wraps within it and the discs are at least 44px apart from the edges.
