# Spectating

Added on 27 October 2026 for spectating (ADR 0012, rules R70 to R80), and amended on 28 October 2026: games against the computer cannot be watched, the exhibition game is gone, Watch live shows quick match games only, and a link game is watched through its own link. U81 is removed and U91 to U95 are new. It extends `home.md`, `game-screen.md` and `board-interaction.md`.

The watching screen is the normal game screen with everything that acts taken away. Nothing on it can change a game, and nothing on it shows a choice before the round resolves (R72).

## The home screen

- **U76** The round icon row gains a "Watch live" button (`watch-live`): a round button with an eye icon and the label "Watch live", the same size and style as the others (U34), placed first in the row. A small badge pinned to the corner of the round button (`live-count`) says how many **quick match** games are live (R80), for example "3 live", so it costs no height. When none are live the badge is not drawn and "No live games" stays as hidden text for screen readers. It is a number only: never a code, a name or which games exist. The count refreshes when the home screen opens and every 10 seconds while it is open and visible, from `GET /api/live`, and never more often (R77).
- **U77** Tapping "Watch live" opens `/watch`, which places the visitor in a random live quick match game (R70). With none live it shows the empty state of U93 and no board. `/watch?game=CODE` watches one particular quick match game (the same `spectate` message with a code that R70 allows); it is for checks and answers exactly like a random request when the game cannot be watched, so a code of a computer game, a game that is over and a code that does not exist all get the same words (R71). A link game is watched at its own address, `/g/CODE` (U92), not at `/watch`.

## The watching screen

- **U78** `/watch` uses the game screen's layout, board and colours: both players' names and avatars, with your-colour and their-colour discs as on the players' screens (the first seat's discs use the ring marker and the second seat's the cross marker, so they differ by shape as well as colour). Above the board a **"Watching live" banner** (`watching-banner`) sits where the round line and the ceiling warning sit on the game screen, and shows the round number beside it. The ceiling warning (U68), the rock (U71) and the result line (U66, U73) all work as they do for the players.
- **U79** There is **nothing to act on** the board: no column hit areas that respond (`column-0` to `column-6` do not exist on this screen), no hover highlight, no ghost disc, no shield badge, no Earthquake badge, no info buttons for them, no timer bar (a spectator does not need to hurry) and no keyboard shortcut for a column or a power-up. The player panels show names, avatars, the shield and the Earthquake as small icons (available, or struck through when used, with the words as hidden text, as in U75) and never "Choosing" or "Ready" (R72). The only buttons are **"Watch another game"** (`watch-another`) and **"Home"** (`go-home`), each at least 44 by 44px.
- **U80** The watcher count (`watching-count`) is shown on the watching screen as a small eye icon and a number, for example "2 watching", in the banner's row or directly under it, so it never costs a row on a 320 x 568 screen (the first-screen rule of `docs/design.md` holds: the whole board, both names and the banner are visible without scrolling). It says "1 watching" when the spectator is alone, and it includes the spectator themselves.
- **U81** *Removed on 28 October 2026.* There is no exhibition game, so there is no "Exhibition" label and no computer players on this screen (R78).
- **U82** When a watched game ends, the end popup of U27 does not appear. Instead a small card over the board (`watch-result`) shows the result, "<name> wins!" or "It's a draw!" (a game that stops without a result says "That game has ended", U83), and says "Next game in 5 seconds" with a count down from 5 (5, 4, 3, 2, then "Next game in 1 second") (a plain number, `aria-live`, no animation). After 5 seconds the browser asks for another random live game (R76) and the screen moves to it. "Watch another game" does it at once, and "Home" leaves. Under reduced motion the number still counts down. The card is compact (at most 300px wide) and centred over the board like U27a.
- **U83** If the server cannot place the spectator (`room_full`, R77), the screen says "The room is full right now. Try again in a moment." with "Home" and, on `/watch`, "Watch another game", and no board. If a game stops while it is being watched (its players left), the spectator is moved on as in U82 with the card saying "That game has ended".

## On the players' screen

- **U84** During a game, each player's screen shows a small eye icon and the watcher count (`watcher-count`): the number is what shows, and the word "watching" is visually hidden text in the same paragraph, so the accessible name reads "2 watching" and a narrow screen has room, next to the round line in the same row as the ceiling warning (U68), and it is hidden while nobody is watching. It is a number only (R75). It is a single line at 320px (smaller type, as in U68), updates when a spectator joins or leaves (the `watching` message) and is an `aria-live` status that is not read out every time it changes (`aria-live="off"`, so a changing number does not interrupt a player mid-round). A friend game never shows it, because a friend game can never have spectators (R71).

## Link games and the empty state (28 October 2026)

- **U91** On the home screen under Quick match, and on the Quick match page, a live count says how many people are playing right now ("3 people playing now", "1 person playing now") from the same `GET /api/live` number, which counts quick match games only (R80). It reads "No one is playing right now" when there are none.
- **U92** A link game is watched at its own address. A visitor who opens `/g/CODE` when both seats are taken is made a spectator by the server (R36) and sees the **watching screen at that address** (the same layout as `/watch`: banner, count, names, board, result line) with the notice **"This game already has two players, so you're watching."** (`spectator-notice`) in place of the "Watching live" banner for the whole time they watch. The notice is one line at every width (a smaller type on a narrow screen), and the screen has only a **Home** button (`go-home`): there is no "Watch another game", because a link game belongs to its two players and there is nothing to move on to. When the game ends the spectator sees the result card of U82 without the count down and without moving on, and keeps Home. A visitor who opens the link of a game that has **already ended** sees the same screen with the result card at once and no board animation: "That game has ended" with who won, and Home.
- **U93** `/watch` with no live quick match game shows no board: a centred card (at most 480px) in the toy style with an eye icon, **"No live games right now"**, a line saying "Start a Quick match and other people can watch you play." and two buttons, **Quick match** and **Home**, each on one line (Q2) and 16px apart (Q4). Hooks: `no-live-games`, `quick-match` (the button), `go-home`.
- **U94** The watching screen of a quick match game shows **"Watching <player> vs <player>"** in the banner in place of "Watching live", with both names as on the players' panels (nicknames without their tags, and at 320px without the word "Watching", which is still read out, so two ordinary names fit one line; a name that is longer still is cut with an ellipsis in the banner, and every name is shown whole, with its tag, in its panel), the **Home** button and **Watch another game** (U79). A link game's watching screen shows the notice of U92 instead, and Home only.
- **U95** The friend waiting screen's card says **"Send this link. The first person to open it plays you, and anyone after that watches."** under "Waiting for your opponent", above the code and the Copy link and Share buttons (U54), in a line at most 480px wide. A player who is the creator is told nothing else; the first other person to open the link is player 2 and sees the game as a player (U55).
